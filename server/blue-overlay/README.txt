Blue theme overlay for the server copy (e.g. public_html/Salesreport1/).
Extract the release zip into the Sales Reporter folder. It replaces index.php and
lead_routing.html with versions that load assets/css/theme.css and assets/js/pwa.js,
and adds manifest.json, service-worker.js, offline.html, fonts and icons.
Original app.js, style.css, api/ and config.php are not touched.
Fonts and icons: copy from public/assets/fonts and public/assets/icons.
